# Simple-Age-Calculator

This Simple Age Calculator is a web-based tool that calculates a user's age based on their date of birth. The application consists of an input field for selecting the birthdate and a button to trigger the calculation. When the user enters their birthdate and clicks the button, the program determines the current age in years and displays the result.

How It Works:
The user enters their birthdate in the input field.
Upon clicking the "Calculate Age" button, the script retrieves the selected date.
The function computes the difference between the current year and the birth year.
It also checks if the birthday has already occurred in the current year:
If not, the age is adjusted by subtracting one year.
The final calculated age is displayed in the result section.
Features:
✔ User-friendly UI with a modern dark theme.
✔ Accurate age calculation considering month and day differences.
✔ Error handling to prompt the user if no date is selected.
✔ Responsive design for different screen sizes.
